# notes/: what each session actually printed

This folder holds the saved, real output of the sessions, so every number
in the record can be traced to what a script printed.

- **Session output:** `session-NN-output.txt` and similar names (for
  example `session-07-check-output.txt` or
  `session-50-e1-experiment-output.txt`). Each DECISIONS finding names the
  file that holds its full output. The prompt for session NN is
  `session-NN.md` in [../docs/sessions/](../docs/sessions/).
- **Audit reports:** `audit-session-*.md`, the four audit reports written
  in sessions 66 to 68b and triaged in DECISIONS D62.
- **Other records** that DECISIONS names, such as
  `session-34-archive-manifest.md` (D46).

Some scripts write their output files here, and the record cites these
files by path, so the folder and its file names stay as they are (D91.2).
These files are part of the record and are not edited after the fact.

Some files contain file paths from the author's own machine (F126.2).
