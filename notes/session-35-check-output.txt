Sizes: ugrd10m_sample.grib2 984,341 B; vgrd10m_sample.grib2 961,389 B;
tcdc_sample.grib2 829,229 B (each ~0.03% of the ~514 MB whole-file f000 size,
i.e. one message out of ~700 in the file).

RESULT: all three extracted messages start with the GRIB2 magic marker and
end with the "7777" end-of-message marker required by the GRIB2 standard —
each is a complete, well-formed, individually-addressable GRIB2 record, not
a truncated or corrupted fragment. This also demonstrates the byte-range
technique itself: a single point-value pull needs only the ~0.8-1.0 MB
message, not the ~500+ MB whole file (see Task 3).
